# 운영자 준비 자료·결정표

수정일: 2026-11-04 · 버전: 1.3 · 사용자 운영 정보 일부 확정; 대표 정보·이메일은 추후 제공

이 표는 개발 착수 전체를 막는 사전 설문이 아니다. 미정이어도 시안·기반·엔진 조사 등 독립 작업은 진행한다. 사업 정보·계산 기준·외부 처리처럼 개발자가 임의로 정할 수 없는 항목만 해당 공개 단계 전에 확정한다.

## 1. 사용자 답변으로 확정한 내용

1. 소재지: **서울 강북구 한천로 1167 3층**.
2. 대표 정보: 사용자가 나중에 제공. **현재 공란 유지**.
3. 초기 상담: **이메일 상담만**. 실제 상담 이메일 주소도 사용자가 나중에 제공하므로 **현재 공란 유지**.
4. 홈페이지의 사주 기능: **무료만 제공**.
5. 유료 AI 풀이: **후속 계획만 작성**. 초기 구현·실제 API 호출·결제·판매는 하지 않음.
6. GitHub 저장소: **[BrawlNote/hakso](https://github.com/BrawlNote/hakso) / Private**, 사용자 생성 및 Edge 접근 확인. 원격은 `https://github.com/BrawlNote/hakso.git`; 배포는 별도 미구현.

대표 정보와 이메일 주소는 현재 다시 요구하지 않는다. 추후 제공될 때 반영한다. 초기 확정 범위는 “홍보+무료 기본 사주+이메일 상담 안내, 이메일 미제공 시 준비 중, 결제/회원/유료 AI 구현 없음”이다. 이메일 상담 자체의 요금·항목·답변 기한은 별도 미정이며 무료라고 추정하지 않는다.

## 5. 홍보 자료와 운영 준비

- 상호 검색 시 연결할 대표 도메인·설명·공유 이미지.
- 기존 네이버 플레이스·블로그·카카오 채널·SNS·예약 페이지가 있다면 실제 URL과 소유 계정.
- 실제 위치가 있으면 건물 입구 찾는 법, 대중교통·주차·예약 필요 여부.
- 현재 주소는 소재지 안내용이다. 방문 상담을 열기 전에는 교통/주차 자료나 방문 예약을 초기 필수 자료로 요구하지 않는다.
- 주력 상담 분야와 자주 받는 질문 5~10개.
- 개인정보를 제거한 실제 질문 유형; 개인 상담 원문은 요구하지 않는다.
- 오픈 후 문의에 답할 담당자와 응대 가능 시간.
- 개발/호스팅·도메인·AI·홍보 광고를 구분한 예산. 광고 집행은 별도 결정.

## 7. 외부에 공개하기 전 확인할 문장

“다음은 공개할 실제 내용이다”라는 기준으로 상호·소개·항목·가격·위치·채널·정책·계산 기준·AI 고지를 한 번에 검수한다. 미정 표시를 제거했다고 사실 확인이 된 것은 아니다. 실제 공개 범위와 사용자의 공개 요청이 확인된 뒤 그 범위로 배포한다.
