# 학소 철학관 홈페이지 기획·개발 인계 패키지

작성일: 2026-11-04 · 개발 환경: macOS · 상태: **기획 문서 작성 완료 / 서비스 구현 전**

수정 버전: 1.3 · 사용자 추가 답변 반영. **초기 구현은 무료 사주 + 이메일 상담 안내이며, 유료 AI 풀이는 계획만 작성한다.**

학소 철학관을 알리고 실제 상담 문의로 연결하는 홈페이지와, 방문자가 직접 이용하는 사주 풀이 기능을 만든다. BrawlNote의 Astro·정적 콘텐츠·Git·Cloudflare 운영 방식을 참고한다. 홍보 효과와 관리 편의가 우선이며, 만세력 계산의 검증과 AI 비용·개인정보 처리를 별도 과제로 다룬다.

## 읽는 순서

1. [요구사항·서비스 기획](docs/01_REQUIREMENTS.md): 만들 서비스, 페이지, 콘텐츠, 미정 사항.
2. [사주·AI·개인정보 기술 명세](docs/02_TECHNICAL_SPEC.md): 계산 기준, 시스템 구조, API, 비용 통제.
3. [실행 계획·검수 기준](docs/03_IMPLEMENTATION_PLAN.md): 작업 단위, 의존성, 테스트, 배포·운영.
4. [운영자 준비 자료·결정표](docs/04_OWNER_CHECKLIST.md): 실제 자료와 공개 전 결정할 내용.
5. [안티그래비티 작업 지시서](ANTIGRAVITY_WORK_ORDER.md): 새 작업에 그대로 전달할 실행 지시.

## 제안하는 출시 순서

| 구간 | 제공하는 가치 | 완료 조건 |
| --- | --- | --- |
| A: 홍보 홈페이지 | 학소 소개, 이메일 상담 안내, 소재지, 글 | 대표 정보·상담 이메일은 공란; 이메일 제공 전에는 상담 준비 중 안내 |
| B: 사주 기본 체험 | 검증된 만세력과 고정된 해석 규칙에 따른 무료 간단 풀이 | 계산 기준 확정, 기준 사례·경계 테스트 통과, 실제 입력으로 동작 |
| C: 유료 AI 풀이 후속 계획 | 상품·비용·데이터·결제·운영 계획만 보관 | 현재 구현·실호출·결제·공개 대상 아님; 추후 별도 요청 시 착수 |
| D: 확장 | 내부 예약, 결제, 상세 유료 보고서, 회원 기능 등 | 실제 이용 근거를 확인한 뒤 별도 착수 |

**최초 목표 범위는 A+B다. 홈페이지의 사주 기능은 무료로 제공한다.** 이메일 상담 자체의 항목·요금·응답 기한은 미정이며 무료라고 추정하지 않는다. C는 유료 AI 풀이의 후속 계획으로만 남기고, 초기 사이트에 AI API·결제·유료 상품 버튼을 구현하지 않는다. B의 계산 검증이 끝나지 않았다면 예시 화면을 실제 서비스로 표시하지 않는다.

- 사용자 요청: 학소 철학관 홍보 홈페이지 + 사주 봐주기, AI 활용 가능, 안티그래비티가 실무 수행, macOS에서 개발 예정.
- `C:\Users\sunwoo\BrawlNote\BrawlNote.github.io`의 로컬 소스에서 Astro/Starlight, Markdown 콘텐츠, Cloudflare Worker 동적 기능, 테스트·문서 운영 구조를 확인했다. BrawlNote 소스는 변경하지 않았다.
- 현재 `Hakso` 폴더에는 이 기획 문서만 만들었다. 사이트, 만세력, API, 배포는 구현·실행하지 않았다.
- 소재지: **서울 강북구 한천로 1167 3층**. 사용자 제공 표기이며 현장·지도 대조는 아직 하지 않았다.
- 초기 상담은 **이메일 상담만** 진행한다. 소재지 표시는 방문 상담 접수를 의미하지 않는다.
- 대표 정보와 상담 이메일 주소는 사용자가 추후 제공한다. 현재 공란을 유지하며 임의 이름·주소·전화번호를 넣지 않는다.
- 상담자 소개·경력·이메일 상담 항목/가격/응답 기한·도메인 등 나머지 운영 정보는 미확정이다.
- 문서의 기본안과 일정은 제안이다. 특히 사주 학파·계산 기준은 학소 운영자가 확정해야 한다.

## 전달 방법

macOS의 새 학소 저장소에 이 문서 패키지를 넣고 `ANTIGRAVITY_WORK_ORDER.md`를 첫 지시로 전달한다. Windows 절대 경로를 맥 경로로 기계적으로 바꾸지 말고 실제 저장소 위치를 확인한다. 새 저장소의 작업 폴더 예시는 `~/Projects/hakso`다.

실무자는 문서를 읽은 뒤 0단계 현황 점검부터 시작하고, 운영 정보가 미정이어도 별도 표시한 시안과 계산 검증 준비를 진행할 수 있다. 미정 정보를 실제 영업 정보로 공개하거나 외부 유료 서비스를 임의로 결제하지 않는다.

## 맥에서 저장소 받기

비공개 저장소에 접근 가능한 GitHub 계정으로 Git 인증을 준비한 뒤 실행한다. 브라우저 로그인과 터미널 Git 인증은 별개다.

```bash
mkdir -p "$HOME/Projects"
cd "$HOME/Projects"
git clone https://github.com/BrawlNote/hakso.git
cd hakso
```

기존 `hakso` 폴더가 있으면 덮어쓰지 말고 원격 주소와 Git 상태부터 확인한다. 받은 폴더를 안티그래비티에서 열고 `ANTIGRAVITY_WORK_ORDER.md`부터 읽도록 지시한다. 초기 저장소에는 기획 문서만 있으며 사이트 코드·빌드·배포는 아직 없다.
